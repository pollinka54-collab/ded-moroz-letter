# Мороз.Письмо

Letter-only веб-приложение: родитель вводит имя ребёнка, проверяет персонализированное письмо на предоставленном шаблоне и скачивает готовый одностраничный PDF формата A4.

В проекте больше нет загрузки фотографий, генерации изображений, AI-провайдеров, GPU-worker или API-ключей.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется.

```bash
npm start
```

Откройте `http://localhost:4173`.

Публичная версия автоматически публикуется в GitHub Pages из папки `public` после каждого push в ветку `main`.

Проверка:

```bash
npm test
```

## Что работает

- ввод и проверка имени ребёнка (до 24 символов);
- живой предпросмотр на исходном шаблоне письма;
- создание одностраничного PDF A4;
- скачивание файла с именем ребёнка в названии;
- сброс результата и создание письма для другого имени;
- адаптивный интерфейс для телефона и компьютера;
- статический Node-сервер с CSP и другими защитными заголовками;
- Dockerfile для размещения на сервере.

Имя обрабатывается только JavaScript-кодом в браузере. Оно не отправляется на сервер, не записывается в логи и не сохраняется в базе данных.

## Что находится под капотом

Искусственного интеллекта здесь нет. Приложение использует:

1. исходный шаблон `public/assets/letter-template.png` для предпросмотра и сборки страницы;
2. имя, введённое родителем;
3. браузерный Canvas для отрисовки имени;
4. небольшой встроенный PDF-сборщик для скачивания результата.

Это делает результат предсказуемым: меняется только поле имени, остальной дизайн письма остаётся тем же.

## Размещение на сервере

Приложение можно разместить на обычном VPS или в любом Docker-хостинге:

```bash
docker build -t ded-moroz-letter .
docker run --rm -p 4173:4173 ded-moroz-letter
```

Для публичного запуска нужен только HTTPS-прокси (например, Caddy или Nginx). База данных, файловое хранилище, очередь и GPU не нужны.

## Стоимость

- AI и генерация: **0 ₽**;
- стоимость одного письма: практически **0 ₽**;
- сервер: от бесплатного тарифа статического хостинга до стоимости небольшого VPS; ориентир базового российского VPS — около **900 ₽ в месяц**;
- домен оплачивается отдельно.

При таком варианте один сервер может обслуживать много пользователей, потому что PDF собирается на устройстве посетителя, а сервер только отдаёт HTML, CSS, JavaScript и шаблон.

## Важное ограничение PDF

Текущая версия визуально сохраняет предоставленный шаблон, но формирует PDF как качественное растровое изображение страницы (1489 × 2105 px), а не изменяет исходное AcroForm-поле внутри `letter-template.pdf`. Для домашней печати этого достаточно. Если потребуется типографское качество или редактируемое поле PDF, следующим шагом стоит подключить прямое заполнение AcroForm.

## Структура

- `public/index.html` — интерфейс;
- `public/styles.css` — адаптивный дизайн;
- `public/app.js` — проверка имени, предпросмотр и сборка PDF;
- `public/assets/letter-template.*` — предоставленный шаблон;
- `server.mjs` — статический сервер и health-check;
- `tests/server.test.mjs` — серверные проверки.
